# 北05加入廠別概念

# 背景

由於之後工研院會有多個廠別，所以需要把廠別的概念加入現在系統中。在三年內的業務會相同，都是做 IG01，因此網站都先用同一個，之後若廠別需做不同業務再討論是否要獨立網站。

**廠別有關：機台、站點、庫存、人員**

- 每個廠房的機台不一樣，機台一定是綁廠房
- 目前工廠只有生產一個產品，但是在不同廠房的機台、站點可能不一樣，這是因為不同廠房的機台可能更有效率，導致站點不需要這麼多…等等。
- 不同廠別的人員不能瀏覽不同廠別的資料，除非此人員所屬廠別有多種

與**客戶、供應商**有關的就不會綁廠別，例如：客戶設定、供應商設定、出貨…
