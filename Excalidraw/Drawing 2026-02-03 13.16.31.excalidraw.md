  我的建議：兩個新 Sheet

  1. purchases Sheet（補貨紀錄）

  專門處理補貨，因為它需要更多欄位：

  │      欄位      │       說明       │

  ├────────────────┼──────────────────┤
  │ supplier       │ 工廠/供應商名稱  │
  ├────────────────┼──────────────────┤
  │ amount         │ 金額             │
  ├────────────────┼──────────────────┤
  │ items          │ 品項說明（選填） │
  ├────────────────┼──────────────────┤
  │ payment_status │ pending / paid   │
  ├────────────────┼──────────────────┤
  │ paid_at        │ 付款日期         │
  ├────────────────┼──────────────────┤

  ├────────────────┼──────────────────┤
  │ created_at     │ 建立時間         │

  2. expenses Sheet（通用支出）

  處理其他雜項支出：

  為什麼建議分開？

  1. 補貨的特殊性
    - 可能需要追蹤「供應商」做統計（哪家工廠花最多錢）
    - 可能需要付款狀態追蹤（有些工廠月結）
    - 未來可能需要關聯「進貨品項」
  2. 其他支出較單純
    - 用「類別」欄位區分即可
    - 不需要複雜的關聯

  ---
  替代方案：全部合併

  如果你覺得分兩個 Sheet 太複雜，也可以只用一個 expenses Sheet，加上 type 欄位區分：
  - purchase（補貨）→ 顯示 supplier 欄位
  - rent / fuel / maintenance / insurance / other（通用）

  這樣前端可以根據 type 顯示不同的表單欄位。

  ---
  問題想跟你確認

  1. 補貨需要追蹤付款狀態嗎？ 還是付完才紀錄？
  2. 需要供應商/工廠的獨立管理嗎？（像 markets 一樣，有自己的 Sheet）
  3. 倉庫租金是固定週期嗎？ 需要像 contracts 一樣自動產生待繳紀錄嗎？
  4. 這些支出需要審核流程嗎？ 還是紀錄了就算？
